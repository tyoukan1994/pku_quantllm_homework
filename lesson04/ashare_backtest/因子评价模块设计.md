# 因子评价：静态、动态与跨阶段稳定性

## 目标与窗口选择

回答三个不同问题：全期平均有没有关系；最近关系是否改变；过去好的阶段之后，有多少次转差。不能用“全期IC显著”代替“关系随时间稳定”，也不能把“未检出变化”写成“已经证明稳定”。

五年数据不必最多只取一年。全样本保留为历史基准；21、63、126、252交易日并列展示，分别观察月度至年度变化。近期诊断默认63日，与更早的252日比较；参考窗可设为126/252/504日，不按样本总长固定比例。短窗更敏感也更嘈杂，长窗更稳但响应慢。一年是候选窗口，不是统计上限。配置在本次评价前固定，结果中记录；不自动挑选相关性最好看的窗口。

首版是**诊断工具**，不是根据评价结果自动翻转因子或配置资金的择时策略。只有五年数据时，独立年度阶段本来就很少；把滚动窗口画得更密，不会产生更多独立样本。

## 1. 输入和边界

- 接入已有DataBundle、Context、历史非ST及流动性筛选，不另造股票池；默认120日有效历史、20日平均成交额至少5000万元、流动性前1500只。覆盖范围仍受给定代码池约束。
- 信号在t日收盘形成；标签为 `adjusted_open[t+1+h] / adjusted_open[t+1] - 1`，默认h=1/5/20交易日，价格乘cumadj。1日标签最早t+2兑现，符合T+1持有期，但不代表真实可成交。
- 信号日和标签起止均须处于评价范围。结束日期之后的标签不读入；起点以前的行情只用于因子预热。
- 动态图按**收益兑现日**而不是信号日更新；保守地在兑现日收盘后视为已知。月度描述表按信号月份归属，二者明确区分。
- 因子方向由用户预先设定+1/-1；不使用全样本符号自动决定“正确方向”。
- 自定义入口 `collect_observations(data, config, score_provider)`：函数接收历史受限的Context，返回股票×因子DataFrame。界面首版提供六个既有量价因子；自定义Python接口已可复用，不执行任意上传代码。自行绕过Context取数仍可能造成泄漏。

## 2. 静态评价

逐日截面计算Pearson IC及Spearman RankIC，再沿时间汇总，不把不同日期的股票直接混成一次相关性。输出IC均值、标准差、不年化ICIR、方向一致率、95%近似区间、配对覆盖率、Q1—Q5平均未来收益及Q5−Q1价差。

秩采用平均秩处理并列值。股票不足、截面常数或收益常数时IC记缺失，不填零。分位组按平均秩划分，不任意拆开同分股票；极多并列值可能形成空组，保留缺失。覆盖率为标签有效股票数/当日因子有效股票数。

这些是相关性与毛收益诊断，不扣交易费用、不模拟涨跌停排队和容量，也没有行业/市值中性化。不能把分组价差当作可成交多空策略的实际收益。

## 3. 动态评价

### 多尺度轨迹

并列展示21/63/126/252日平均RankIC、近期窗口95%区间和最近30日状态。窗口按真实交易日历切片，缺失日不压缩；至少80%有效IC且至少20个有效观测才展示对应窗口均值。常数IC不会产生无穷ICIR或假装零误差的确定性结论。

### 重叠标签与不确定性

HAC标准误采用Bartlett权重，带宽至少h−1，同时取常见自动带宽 `floor(4*(T/100)^(2/9))`，以反映重叠未来收益及部分序列相关。缺失值保留时间间隔。均值区间为 `mean ± 1.96*SE_HAC`，是大样本逐点近似，不是相关系数参数的精确有限样本区间，也不是顺序检验。

有效观测少于 `3*(带宽+1)` 时不输出区间，也不触发衰减对照；均值仍可作描述展示。这是防止短窗配长预测期产生虚假精度的保守工程门槛，不是统计保证。较长预测期应配合较长窗口，并以非重叠分段作描述对照；首版不报告“下一期盈利概率”。

### 历史参考对照

近期窗默认63日；参考窗取它之前252日，并在中间留h−1个兑现日间隔，避免两段共享同一持有期收益。用固定方向后的IC比较“近期均值−历史均值”，对该差值一并计算HAC近似上界，而不是比较两条高度重叠的移动均线后声称发现独立变化。

### 状态而非神秘总分

优先级为：

| 状态 | 判定 |
|---|---|
| 样本不足 | 近期窗口长度或有效IC数未满足要求 |
| 近期反向 | 近期方向调整IC的95%上界低于−实用阈值 |
| 近期衰减 | 历史参考IC高于阈值，且近期减历史差值的95%上界低于−阈值 |
| 正向支持 | 近期方向调整IC的95%下界高于实用阈值 |
| 证据不足 | 其余情况，包括相关弱、波动大或区间不可估计 |

默认实用阈值0.01，是可配置研究约定，不是公认投资门槛。连续3个诊断日同类警报单列提示；窗口重叠，**不是3次独立确认**。首版不控制全时程、多因子、多窗口的整体误报率，不输出“95%稳定概率”。

## 4. 上一阶段好、下一阶段差

按63个交易日切非重叠块，每块只保留买入、卖出日期均在块内的标签；段末跨界标签排除。尾部不足完整块、有效样本不足的块不进入转移统计。列出完整块均值和样本数，并显示“上一块IC>阈值后，下一块IC<−阈值”的次数/可比较次数。

这是对用户关心的反转风险的直接描述，而不是独立预测模型。块内日IC仍可能重叠，统计只提供次数，不把股票数当独立阶段数，不给稀疏阶段对制造显著性。20日预测期在短分段中样本可能不足，应保留不足状态而不降低门槛凑结果。

## 5. 平台结构

```text
因子评价页面
  → EvaluationStore（独立请求、结果、错误记录和哈希）
    → collect_observations（历史Context与前瞻收益边界）
    → evaluate_observations
      ├─ 全期IC与分组收益
      ├─ 收益兑现日驱动的动态诊断
      ├─ 非重叠分段与相邻反转
      └─ 月度描述表
```

保存在 `workspace/evaluations/factor-<时间>-<随机ID>/`，每次创建新记录，不覆盖已有研究或回测。输出request.json和六张CSV，带输入文件及结果哈希，支持ZIP导出。资金、费用、交易规则仍属于原回测模块；本模块不会修改原冻结策略或既有成绩。

## 6. 后续增强（尚未实现）

1. **稳定性的前瞻验证**：在开发期固定状态规则，逐步前推，将每个诊断与其后的完整季度结果配对，检验诊断是否真能改善下一期选择；不能用事后分类回填历史交易。
2. **条件稳定性**：按当时已知市场趋势、波动、流动性分层，同时显示股票池变化，区分市场状态依赖和构成漂移。
3. **稳健性**：分块Bootstrap、带多重尝试校正的结构突变研究、股票池交集对照和不同抽样相位；不能把反复报警当独立p值。
4. 行业/规模中性化、更多技术与文献因子适配、自定义因子管理及稳定性评分的独立验证。只有规则确有前瞻效用，才考虑接入动态权重。
