# 技术与文献策略

平台新增两个通用模板，策略仍通过同一个 `on_close(context)` 接口运行，不影响原有回测、参数搜索和用户策略编写。

## 在界面使用

1. 进入“策略研究 → 策略探索”，查看开发比较、确认表现、滑点压力及所有失败候选。
2. “打开回测明细”可查看真实净值、成交、委托、持仓和费用，不只是因子收益。
3. 在“策略库”选择“RSI与技术选股”“文献量价选股”或已保存的探索候选，修改参数并另存。
4. 在“回测”选择策略、日期和账户配置。课程参数为10亿元、佣金双边各万一、卖出印花税万五、上日成交额1%容量。

本次探索不运行2025—2026年考核。开发区间为2020—2023年，依据年度稳定性选择有限候选，再确认2024年。两批研究分开事前列明候选、分别冻结，不能把新增试验包装成同一次盲测。

## RSI与技术选股

文件：`strategies/technical_selection.py`，核心：`ashare/technical.py`。

```json
{"mode":"rsi_rebound","top_n":100,"rebalance_days":1,"entry_threshold":30,"exit_threshold":60,"max_hold":10,"trend_window":0}
```

`mode` 可取：

| 值 | 策略 |
|---|---|
| rsi_rebound | RSI14从买入阈值下方向上穿越 |
| rsi_pullback | RSI2低于买入阈值，常配MA200过滤 |
| bollinger_rebound | 20日布林带下轨外回到轨内 |
| reversal | 5日或20日反转，指定lookback |
| momentum | 60日跳过最近5日，或120日跳过最近20日 |
| breakout | 此前20/60日最高价突破，10/30日低点退出 |
| ma_trend | MA20/60或MA60/120正乖离排序 |
| low_volatility | 20/60日低波动，指定lookback |
| lowvol_reversal | 低波动与5日反转百分位加权 |
| lowvol_momentum | 低波动与60/120日动量百分位加权 |
| amount_reversal | 成交额放大×5日反转 |
| close_pressure | 成交额加权的K线收盘位置反转 |
| defensive_regime | 低波反转组合，市场宽度不足时减半仓 |

RSI按Wilder平滑：前n个涨跌幅的简单平均初始化，后续平滑系数1/n。连续缺失后重新预热；连续全平行情明确约定RSI=50；只有上涨为100、只有下跌为0。不是用简单滚动均值代替Wilder版本。线上逐日计算与离线因果缓存有等价测试。

持仓满N日从实际买入后首次收盘算第0日，满N日后发出下一日开盘退出信号。不把未成交委托当成已建仓。`rebalance_days` 控制调用目标生成的间隔；事件类探索使用1，排名类使用5/10/20。目标最多100只，但卖出受阻和研究模式不足1股的残余可能使实际持仓代码数更多。

## 文献量价选股

文件：`strategies/literature_selection.py`，核心：`ashare/literature.py`。

```json
{"factor":"high252","top_n":100,"rebalance_days":20}
```

| factor | 定义/改编 |
|---|---|
| high252 | 当前复权收盘价/252日最高复权收盘价 |
| high252_lowvol | 上述高点信号与20日低波动百分位各50% |
| intraday_reversal | 负的过去5日log(收盘/开盘)之和 |
| overnight_reversal | 负的过去5日log(当日复权开盘/前日复权收盘)之和 |
| amihud_low / amihud_high | 过去20日平均abs(日收益)/成交额的低/高端 |
| alpha33 | open/close−1，横截面排序等价于Alpha101论文#33 |
| alpha101 | (close−open)/(high−low+0.001)，使用原始同日价格 |
| alpha101_reverse | 上述K线实体信号反向改编，复权价格口径 |
| range_reversal | 5日反转/过去20日ATR占价格比例 |
| amount_expansion | 5日/20日平均成交额；不是原文成交量指标 |
| price_amount_divergence | 负的20日日收益与log成交额变化的相关系数 |

不把成交额当成交股数，不把num_trades未经确认当成交量，不伪造VWAP和换手率。缺少成交量、自由流通股数、行业、市值等字段的原策略不声称完全复现。

所有信号用截至当日收盘的信息，下一交易日开盘尝试成交。隔夜/日内收益拆分只是历史选股信号，不意味着能够当天买当天卖，也不意味着获得此前已经发生的隔夜收益。

## 如何理解结果

- 24个技术候选和12个文献候选均完整保留，不删除负收益或低仓位版本。
- 平均仓位很低但夏普较高，不等于适合10亿元账户；开发门槛包含平均仓位至少20%。
- 2024年确认、滑点测试不用于重选此前冻结的候选；未通过开发门槛的诊断候选不自动推荐。
- 5/10bp滑点不是只从原净值机械扣费：价格取整、日线高低价拒单、涨跌停和容量会改变成交与后续持仓，收益可能非单调，应检查委托表。
- 原始资料中的多空或高频收益不能直接移植到A股多头、T+1、10亿元容量账户。网络上“表现好”的图不作为本平台已验证结果。
- 本次开发与确认不要求期末离场，持仓按市值计入，不等同于原作业末日清仓考核。老师给定代码池仍可能存在幸存者偏差，复权与开盘冲击均有研究近似。
