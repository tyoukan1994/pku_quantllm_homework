# 界面设计说明

## 参考

- [QuantConnect：Backtesting Results](https://www.quantconnect.com/docs/v2/cloud-platform/backtesting/results)。参考其“关键指标—图表—成交/订单/日志”的信息层次。
- [TradingView：Strategy Report](https://www.tradingview.com/support/solutions/43000764138-tradingview-strategy-report-how-to-start/)。参考其将绩效、交易明细和属性分区展示的方式。

这里只借鉴信息组织，不复制商标、原界面素材或专有实现。

## 落地

| 区域 | 实现 |
|---|---|
| 导航 | 深蓝侧栏、统一图标、活动项高亮、数据连接状态 |
| 顶部 | 面包屑和本地运行环境标记；不放口号或宣传横幅 |
| 回测 | 左侧参数卡，右侧四项绩效指标与图表/明细工作区 |
| 空状态 | 明确“未运行”，指标为“—”，图表区不绘制虚构行情或收益 |
| 策略库 | 左侧策略信息、默认参数及导入；右侧深色源码编辑区与保存操作 |
| 策略研究 | 候选范围与训练配置并列；研究记录另页签查看 |
| 实验记录 | 真实运行数量、完成/失败状态、记录表和多选比较 |
| 数据与规则 | 连接设置和撮合口径并列，检查结果单独展开 |

统一使用蓝色主操作、浅灰工作区、白色功能面板、轻边框和紧凑次级文字。保留设计层次和运行状态，删掉与操作无关的空泛文案。

## 与业务的关系

指标、图表和状态对应真实运行；初始工作台不自动展示旧策略成绩。策略、区间、资金和交易设置仍可修改，平台不因某次因子研究而变成单策略展示页。

样式在 `ashare/ui/design.py` 和 `.streamlit/config.toml` 中，页面在 `ashare/ui/` 中，应用服务和回测引擎不依赖这些样式。
