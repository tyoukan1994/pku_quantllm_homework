# 第五讲：因子与因子评价

在已有A股策略平台中增加独立因子评价模块，检查量价因子与未来收益的关系是否随时间变化。

- 静态评价：IC、RankIC、ICIR及分组收益。
- 动态评价：21/63/126/252交易日滚动，以及近期相对历史参考窗口的衰减和反向诊断。
- 跨阶段评价：非重叠分段，统计上一阶段正向之后、下一阶段转负的次数。
- 五年样本保留历史基准，一年不是窗口上限；只使用已经兑现的收益更新诊断，不保证未来有效。

## 运行

复用[平台安装与运行说明](../lesson04/ashare_backtest/README.md)，启动后在左侧选择“因子评价”。模块不依赖特定交易策略，记录独立保存，可导出CSV和配置。

全套101项测试通过；以100个股票代码、2020—2024年行情完成小范围联调。这是流程验证，不是全市场策略结论。后续需要以逐步前推方式检验诊断对下一阶段是否有预测价值。

本次仅公开评价模块、相关界面、测试、设计说明与截图；不包含原始行情、私有历史状态、凭据或完整运行目录。第四讲的原报告与既有结果保持不变。
